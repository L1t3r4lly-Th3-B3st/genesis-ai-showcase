# Genesis AI — public showcase

This repository is for a **public, static overview** of Genesis AI, an independent AI education and engineering research project.

The original Genesis AI source code and its private research server are **not** included here. The site does not expose secrets, run any backend, or claim to host a working AI chatbot.

## Publish with GitHub Pages

1. Create a **new public GitHub repository** named `genesis-ai-showcase` (do not publish the existing private `genesis-ai` repository).
2. Add `index.html` and this `README.md` to the root of the repository.
3. Go to **Settings → Pages**, select **Deploy from a branch**, choose **main** and **/(root)**, then save.
4. Wait for the deployment to finish and open the GitHub Pages URL shown in GitHub Settings.

## Source accuracy

The current capabilities summarized on the site come from the private Genesis AI V6.3 project README. Proposed research milestones are explicitly marked as planned, not achieved.

## Safe sharing

Do not include API keys, tokens, private personal contact information, or the contents of the private backend repository in the public showcase. Review any proposed additions before publishing.
